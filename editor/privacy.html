Privacy Policy

Last updated: July 27, 2026

This policy covers the Bihar Police Notebook Chrome extension and the website editor. They ship as separate packages: the extension only launches the editor tab; the editor is the static site where you write. Your documents stay on your device — we do not collect them.

1. Data Collection

We collect no personal data. There is no account, no sign-in, and no cloud sync.

  • No analytics, tracking, cookies, or fingerprinting
  • No ads
  • No selling or sharing of your data

2. Local Storage

Letters and diaries are stored only in your browser (IndexedDB) on this device. They never leave your computer as part of how this app is built.

The Chrome extension package contains only a toolbar launcher (manifest, background script, icons). It opens or focuses the editor tab. It does not read other websites, and it does not see or send your documents. GitHub Pages serves the editor files only — not your notes.

3. Transliteration

When you type in Hinglish mode, suggestion requests go to Google Input Tools over the network so Devanagari candidates can be shown. Only the text you are typing for suggestions is sent in those requests — not your saved document history. Offline typing still works without suggestions.

4. बोलकर लिखें (Dictation)

The floating microphone lets you write by speaking (Hindi or English–India). The mic is on only while dictation is listening — you will see a clear indicator on the button.

  • Whenever Chrome’s offline language pack is installed, speech is converted on your computer. Audio does not leave the device.
  • If an offline pack is not available, we ask you first before using Google’s online recognition. Only if you allow it is audio sent for recognition.
  • This app does not record, store, or upload your audio. Recognition text is inserted into your document on this device like normal typing.

Note: Hinglish typing suggestions already use Google Input Tools over the network, so the app is not fully offline in that mode either.

5. Shortcuts

Keyboard shortcuts in the editor (macOS: use ⌘ instead of Ctrl):

Shortcut Action
Ctrl + Shift + D Start / pause / resume dictation (बोलकर लिखें)
Esc End dictation if active; otherwise close History
Ctrl + P Export / print PDF
Ctrl + N New document
Ctrl + H or B Toggle History sidebar

6. Data Deletion

  • Delete a document from History anytime.
  • Clear all documents by clearing this site’s data in your browser settings, or by uninstalling the extension (that does not remove notes stored by the website origin — clear site data for that).

7. Your Rights (GDPR)

Because we do not collect or store your personal data on our servers, there is nothing for us to access, export, or delete on your behalf. You control everything that lives in your browser.
